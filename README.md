# Creative Solutions Team - Portfolio Website

A modern, responsive portfolio website built with React and React Router.

## Features

- **5 Pages**: Home, About, Services, Portfolio, Contact
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile
- **Modern UI**: Clean design with smooth animations and hover effects
- **Form Validation**: Contact form with email validation
- **Portfolio Filter**: Filter projects by category
- **Sticky Navbar**: Navigation bar stays at top when scrolling
- **Mobile Menu**: Hamburger menu for mobile devices

## Services Offered

1. Web Development
2. Photography
3. Logo Design
4. Data Analysis
5. Data Entry

## Technology Stack

- React 18.2.0
- React Router DOM 6.8.0
- HTML/CSS (No frameworks)
- JavaScript (ES6+)

## Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser

## Build for Production

```bash
npm run build
```
